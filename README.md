## Features
File Cataloger is a Python-based file indexing and organization tool that scans directories, catalogs files, supports custom tagging, filename and category searching, size-based filtering, and persistent folder tracking. The application includes robust data integrity protections such as catalog validation, corruption detection, atomic saves, automatic backups, duplicate prevention, stale entry cleanup, and tag sanitization to ensure catalog reliability and recovery from failures.
